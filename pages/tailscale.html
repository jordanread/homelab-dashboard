Tailscale

Zero-config WireGuard VPN mesh. Access The Hold from anywhere in the world as if you're home.

What it does

Tailscale creates a private mesh network between all your devices using WireGuard under the hood. Once connected, your phone or laptop can reach the Pi's LAN IP directly — even through a hotel Wi-Fi, cellular, or any NAT — without any port forwarding on the router. It just works.

The Pi runs Tailscale as a sidecar container and advertises itself as a subnet router, exposing the full 192.168.1.0/24 LAN to connected devices.

Connecting a new device

  1. Install the Tailscale app from tailscale.com or your app store.
  2. Sign in with the shared Tailscale account credentials (ask Jordan).
  3. Once connected, you'll get a 100.x.x.x Tailscale IP for each device.
  4. Access services via the Pi's Tailscale IP or by using the Pi as a subnet router.
Subnet routing: If the Pi is configured as a subnet router, you can reach all 192.168.1.x addresses (and thus all *.lan names, if you also set Tailscale DNS) remotely without changing anything.

Using *.lan names remotely

To resolve *.lan hostnames over Tailscale, either:

  • MagicDNS + nameserver override: Set the Pi's Tailscale IP as a custom nameserver in the Tailscale admin console for your tailnet, pointing lan queries to Pi-hole.
  • Direct IP: Use the Pi's 100.x.x.x Tailscale IP directly in browser: http://100.x.x.x:80 with a Host header override (less convenient).

Checking connection status

docker exec tailscale tailscale status
