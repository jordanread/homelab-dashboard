Joplin Server

Shared markdown notes, to-dos, and lists for the Flomads — synced across all devices, no cloud.

↗ Open Joplin Web

What it does

Joplin Server is the sync backend for Joplin, the open-source markdown note-taking app. Both Jordan and the Admiral run the Joplin app on their phones and laptops, and all notes sync through this private server. Shared notebooks are visible to both users — perfect for shared to-do lists, trip notes, grocery lists, and research.

Setting up a new device

  1. Install Joplin from joplinapp.org or your app store (it's free).
  2. Go to Settings → Synchronisation.
  3. Set Sync Target to Joplin Server.
  4. Server URL: http://notes.lan
  5. Enter your username and password (ask Jordan for credentials).
  6. Tap Synchronise — your notes will download in seconds.
Away from home? Set the server URL to the Pi's Tailscale IP instead of notes.lan and sync works over VPN from anywhere.

Shared notebooks

To share a notebook with the other user, right-click (or long-press) the notebook and choose Share notebook. Enter the other user's email address. Changes sync in both directions — great for collaborative lists.

Tips for the Admiral

  • Use the To-do note type (checkbox icon) for lists — items can be checked off on any device.
  • Notes support full Markdown: headers, bold, italics, tables, links.
  • Attach photos directly to notes — they sync to all devices.
  • The web interface at notes.lan works fine in a browser if you don't want the app.
