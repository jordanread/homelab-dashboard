The Hold Local CA

Caddy generates a local Certificate Authority for *.lan domains. Install it once per device and you'll get a green padlock on every service — no more security warnings.

⬇ Download Certificate

thehold-ca.crt · Local CA · Do not share externally

  1. Download the certificate above — tap "Allow" when prompted.
  2. Go to Settings → General → VPN & Device Management.
  3. Tap the downloaded profile and tap Install. Enter your passcode.
  4. Go to Settings → General → About → Certificate Trust Settings.
  5. Toggle on The Hold Local CA and tap Continue.
  1. Download the certificate above.
  2. Go to Settings → Security → More security settings → Install from storage (path varies by manufacturer).
  3. Find and select thehold-ca.crt.
  4. Name it TheHold Local CA and choose CA Certificate.
  5. Tap OK. You may need to set a screen lock if not already set.
  1. Download and double-click thehold-ca.crt — it opens Keychain Access.
  2. Select the System keychain and click Add.
  3. Find The Hold Local CA in the list and double-click it.
  4. Expand Trust and set When using this certificate to Always Trust.
  5. Close the window and enter your password to confirm.
  1. Download thehold-ca.crt and double-click it.
  2. Click Install Certificate.
  3. Choose Local Machine and click Next (requires admin).
  4. Select Place all certificates in the following store → Browse → Trusted Root Certification Authorities.
  5. Click Finish and confirm the security warning.
sudo cp thehold-ca.crt /usr/local/share/ca-certificates/ sudo update-ca-certificates

For Firefox on Linux, you may also need to add it in Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import.
